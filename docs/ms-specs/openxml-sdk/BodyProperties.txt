## Remarks

[ISO/IEC 29500-1 1st Edition]

**bodyPr (Body Properties)**

This element defines the body properties for the text body within a shape.

[_Example_ : Consider a shape with a text body that has some formatting properties associated with it. For the
formatting of text body properties, the bodyPr element should be used as follows:

    
    
    <p:sp>  
      …  <p:txBody>  
        <a:bodyPr>  
          (text body properties)    </a:bodyPr>  
      …  </p:txBody>  
    </p:sp>  
    

_end example_]
