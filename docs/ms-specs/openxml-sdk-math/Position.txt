## Remarks

[ISO/IEC 29500-1 1st Edition]

**pos (Position)**

This element specifies the position of the bar or group character in the
parent object; the default is _bot_. Whether the element is absent or present
without the val attribute, the default of the val attribute is _bot_.
[_Example_ : The XML representation for the mathematical overbar is:

    
    
    <m:bar>  
      <m:barPr>  
        <m:pos   m:val="top"/>  
      </m:barPr>  
      <m:e>  
        <m:r>  
          <m:t>a</m:  
    t>  
        </  
    m:r>  
      </m:e>  
    </m:bar>  
    

_end example_]

Parent Elements  
---  
barPr (§22.1.2.8); groupChrPr (§22.1.2.42)  
  
[_Note_ : The W3C XML Schema definition of this element’s content model
(CT_TopBot) is located in §A.6.1. _end note_]

� ISO/IEC29500: 2008.
